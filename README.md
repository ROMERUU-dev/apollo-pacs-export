# Apollo PACS export

Exportacion estatica de pantallas/prototipo para Apollo PACS.

## Contenido

- Archivos `.dc.html` con las vistas exportadas.
- `android-frame.jsx`, `store.js` y `support.js` usados por la exportacion.
- Capturas en `screenshots/` y `uploads/`.

## Nota

Este ZIP no contiene un backend desplegable ni una estructura de API. No incluye
`Dockerfile`, `package.json`, `requirements.txt`, `.env` ni scripts de servidor.

Para descargarlo en un servidor despues de publicarlo en GitHub:

```bash
git clone <URL_DEL_REPOSITORIO>
```
